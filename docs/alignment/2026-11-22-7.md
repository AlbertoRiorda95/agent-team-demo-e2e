## What changed
`services/store/` exists: a Gradle 9.9.2 wrapper project (Kotlin DSL, Java 25
toolchain) with Flyway `V1__baseline.sql`, a NATS connection at start-up,
JUnit 5 tests and Testcontainers tests (PostgreSQL 17, NATS).

## What the others relied on (before → after)
Nothing existed before; this is the start-up interface that foundations row 11
(Dockerfile, compose) builds on:
- Build: `./gradlew build` (the CI `store` job's command; the tests need
  Docker). Runnable distribution: `./gradlew installDist` puts
  `bin/store` and `lib/*.jar` in `build/install/store/` (main class
  `trajectory.store.Main`); it needs a Java 25 runtime.
- Configuration: `DATABASE_URL` (`postgresql://host[:port]/db` as in
  `.env.example`, or `jdbc:postgresql://...`; credentials in the URL are
  refused), `DATABASE_USER`, `DATABASE_PASSWORD`, `NATS_URL` (default
  `nats://localhost:4222`). No port, no new environment variable.
- Start-up order: Flyway migrate, then NATS connect. Each is retried with
  backoff (0.5 s doubling up to 30 s) and logged as
  `{"level":"error",...,"health":"degraded"}`; it never crashes. Invalid
  configuration: logs `invalid configuration` and exits with code 2.
- Logs: one JSON object per line on stderr
  (`{"ts":...,"level":...,"service":"store","msg":...}`); the password and
  NATS credentials are never written.
- Stops on SIGTERM/SIGINT (shutdown hook closes NATS); as any JVM, the exit
  code after SIGTERM is 143.
- **No health endpoint**, as for the propagator (`docs/alignment/2026-11-22-5.md`):
  the spec's Reuse names no HTTP library for store and an HTTP port would be a
  new port/variable. Health is internal (`StoreService.health()`: `ok` once
  migrated and connected to NATS). The criterion "docker compose ps shows all
  healthy" and the error case "health check answers degraded (503)" need the
  same decision as for the propagator: a process-liveness healthcheck in the
  Dockerfile, or a probe (for Java the JDK's built-in `HttpServer` needs no
  dependency, but needs a port) added in a backend task. Designer to decide.
