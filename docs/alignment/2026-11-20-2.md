## What changed
The root npm workspace, the base lint and TypeScript configs, `compose.yml`
(NATS with JetStream, PostgreSQL 17) and `.env.example` now exist: they set
the environment variables, ports and shared configs the service skeletons
(foundations tasks 2-10) build on.

## What the others relied on (before → after)
Nothing existed before; this is the interface the next tasks use:
- Workspaces `services/viz-web`, `services/control-web`,
  `libs/trajectory-proto`, `packages/ui-tokens`. Root `npm run lint` runs
  ESLint (`eslint.config.js`) on the whole repository; root `npm run
  typecheck`, `npm test` and `npm run build` run each workspace's
  `typecheck`, `test` and `build` scripts (`ci/npm-workspaces.sh`), so each
  workspace must define them under those names. The CI `web` job now calls
  the root scripts.
- Each workspace `tsconfig.json` extends `../../tsconfig.base.json` (strict,
  `moduleResolution: Bundler`, `noEmit`, `verbatimModuleSyntax`).
- `@bufbuild/buf` 1.75.0 is a root dev dependency: `npx buf lint|generate`.
  Its bundled Go binary contains `golang.org/x/net v0.61.0` (GO-2026-6860,
  High). The user approved (PR #54, option b) a grype ignore in `.grype.yaml`
  for that advisory only, restricted to `golang.org/x/net` under
  `node_modules/@bufbuild/buf-*`, **expiring 2027-01-19**. buf stays a
  dev/CI tool: never copy it into an image or a deployed service. Nothing
  else is ignored and the severity threshold is unchanged.
- Environment (`.env.example`): `NATS_URL=nats://localhost:4222` (in compose
  `nats://nats:4222`); `DATABASE_URL=postgresql://localhost:5432/trajectory`
  (in compose host `postgres`) with the credentials in `DATABASE_USER` and
  `DATABASE_PASSWORD`, not in the URL; `API_PORT=8000`, `VIZ_WEB_PORT=5173`,
  `CONTROL_WEB_PORT=5174`.
- Ports on the host: NATS 4222 (client) and 8222 (monitoring), PostgreSQL 5432.

To confirm: `DATABASE_URL` uses the `postgresql://` form; store (JDBC) must
prefix it with `jdbc:` or the variable's format must change for everyone.
